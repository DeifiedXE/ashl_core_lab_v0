# ASHL Core v1 Observation-Aligned Product Imagination v0

This document describes the human-readable imagined shape of ASHL Core v1 after
first-stage observation alignment succeeds.

It is not an implementation, roadmap, legacy alignment index, dataclass package,
runtime loop, old-repo migration, or capability claim.

Plain wording:

> 先描述清音 v1 在第一階段成功後，資料會怎麼從觀察、學習、記憶、思考、具身輸出之間流動。先看見未來成品的輪廓，再決定文件和資料結構怎麼對齊。

## What Observation-Aligned Means

觀察對齊後，不是清音看懂世界。
而是硬軟感知模組產出的資料，能被學習性泛化應用模組消化，能被五重記憶模組整理，再能被思考運算模組讀回。

The minimal aligned flow is:

```text
觀察資料
→ 可讀資料
→ 學習消化
→ 記憶化應用資料
→ 思考訊號
→ 行動訊號
→ 新觀察
```

This means the first-stage product is successful when observation output can
circulate through learning, memory, thought, and body signal without pretending
to be semantic vision, long-term learning, or autonomous action execution.

## First-Stage Product Imagination

清音接收到一個外部或沙盒事件。
硬軟感知模組把它編譯成可讀資料。
擬態內分泌模組提供當前狀態調控訊號。
學習性泛化應用模組把感知資料與內分泌資料消化成學習結果。
五重記憶模組把學習結果分類、路由、整理成記憶化應用資料。
思考運算模組讀取記憶化應用資料與內分泌訊號，產生思考運算模組訊號。
擬態具身模組把思考訊號編譯成行動訊號。
行動造成新的結果。
新的結果再次進入硬軟感知模組。
循環繼續。

The imagined first-stage circulation is bounded to records and data shapes. It
does not require open-ended execution.

## A. User-Visible Product Imagination

使用者不會看到清音突然會聊天。

使用者會看到一個最小循環記錄：

- 她觀察到什麼。
- 資料被怎麼消化。
- 記憶化資料怎麼形成。
- 思考訊號怎麼產生。
- 行動訊號怎麼回到下一輪觀察。

The visible output is a small, inspectable circulation record. It should make the
movement of data understandable without claiming inner experience, semantic
understanding, or live autonomy.

## B. Internal Data Flow Imagination

The first-stage six-module flow is:

```text
硬軟感知模組
→ 學習性泛化應用模組
→ 五重記憶模組
→ 思考運算模組
→ 擬態具身模組
→ 再回到硬軟感知模組
```

擬態內分泌模組 supplies state modulation signals across the flow. It may
influence:

- 感知靈敏度
- 學習消化權重
- 思考偏向
- 行動傾向

It must not directly replace thought decision-making, create purpose, or output
action by itself. In this imagined product, endocrine signals are context and
weighting inputs, not decision authority.

## C. Deferred Three-Line Interface Imagination

These three lines exist as future interface positions only:

- 獨立音訊模組：未來輸出口，目前只保留位置。
- 無限制能力橋接及可操作結構視覺化編譯模組：未來外部能力感知與操作接口，目前只保留位置。
- 稽核邊界模組：未來旁路監督者，目前只保留位置。

The first-stage imagination does not implement voice, bridge, or governance
runtime. It only leaves clean connection points so later work can attach without
rewriting the first-stage circulation.

## Concrete Sandbox Example

Event: 前方被擋住。

First-stage imagined data circulation:

```text
硬軟感知模組:
  產生 blocked / front_obstacle 可讀資料。

擬態內分泌模組:
  產生輕微 cortisol_like 與 norepinephrine_like 調控訊號。

學習性泛化應用模組:
  消化成「這次前方行動受阻」的學習結果。

五重記憶模組:
  整理成可供思考讀取的記憶化應用資料。

思考運算模組:
  產生「降低直接重試，傾向觀察或改向」的思考訊號。

擬態具身模組:
  產生 observe_or_adjust 的行動訊號。

下一輪觀察:
  確認環境是否改變。
```

This is product imagination, not implemented capability. It must not be written
as Qingyin truly understanding obstruction. It is not proof of learning.

本文件只描述第一階段觀察對齊後的成品輪廓，不作為 runtime、能力完成、語音、長期記憶、行動執行或學習證明。
