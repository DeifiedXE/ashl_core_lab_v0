# Phase0 Thought Memory Action Parallel Loop Plan

Scope: ASHL Core Phase0 thought / memory / action integration.
Boundary note: this document is not approval, not runtime behavior, and not authorization for the next package.

## Plain Goal

Build the smallest safe loop where Qingyin can:

1. preview a possible action from temporary same-session memory,
2. compare that preview with existing sandbox action evidence,
3. keep a temporary working-memory trace of the comparison,
4. later allow a separate package to turn that checked trace into a bounded same-session signal.

In plain words: thought, action, and memory should touch each other, but none of them gets to secretly become command authority.

## Three Lines

### Thought Line

Thought is preview.

It may say: "Given what I remember in this same session, this candidate might make sense."

It must not:

- execute action,
- claim the preview already happened,
- write long-term memory,
- prove learning.

### Action Line

Action evidence comes from the existing sandbox action line.

It may say: "This action-line record already selected, finalized, commanded, executed, observed, fed back, applied record-only feedback, and reordered advisory candidates inside sandbox boundaries."

It must not be bypassed by thought or memory.

### Memory Line

Memory is temporary same-session working memory at this stage.

It may say: "This preview and this observed action-line evidence were linked in this one cycle."

It must not:

- become Long-term/Core/Archive Memory,
- write retention,
- create a habit or skill anchor,
- influence predictor,
- change production behavior.

## Current Endpoint

Current endpoint after b171:

```text
b169 advisory reordering evidence
-> b170 one-cycle thought/memory/action mini-loop trace
-> b171 record-only consistency evaluation
```

b171 only checks that:

- thought preview candidate matches the action observation candidate,
- working memory links preview and observation,
- preview is not treated as reality,
- no temporary signal, candidate hint, next-cycle read, new action, memory write, predictor use, production behavior, or proof claim is created.

## Safe Future Route

Each future step needs its own package and tests.

1. Temporary signal boundary:
   allow a valid b171 consistency evaluation to enter a future temporary same-session signal package.

2. Temporary signal record:
   create a record-only signal such as "this loop was internally aligned"; still no candidate hint or action change.

3. Readback boundary:
   allow a future thought package to read the temporary signal as context only.

4. Candidate hint boundary:
   allow the read context to become a candidate hint only.

5. Candidate ordering boundary:
   allow the hint to enter candidate ordering under existing arbitration rules.

6. Action-line integration:
   let existing selected_action -> final_action -> direct_command -> execution boundaries handle action.

7. Loop audit:
   verify that one bounded loop happened without leaking into production, memory persistence, predictor influence, or proof claims.

## Hard Blocks

Until separate packages explicitly open them, this plan does not allow:

- selected_action, final_action, direct_command, or execution,
- new outcome observation,
- candidate score mutation,
- runtime next-cycle ordering change,
- long-term memory write or retention write,
- memory admission,
- habit or skill anchor creation,
- predictor read, influence, or mutation,
- direct endocrine or tendency feed,
- production behavior,
- proof of learning, consciousness, or autonomy.

## One-Line Summary

Phase0 should make thought, action, and memory meet in a tiny sandbox loop first; only later may a checked loop become a bounded signal, and even that signal still does not get to act by itself.
