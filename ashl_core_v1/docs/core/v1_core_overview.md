# ASHL Core v1 核心總覽

## 定位

ASHL Core v1 是一次乾淨重寫。它以九器官為正本，從觀察、學入、記憶、思考、具身輸出建立第一階段循環。

v1 不是把舊 package 名稱搬過來；舊文件只提供概念來源。新的核心文件只保留器官功能、資料流與成長軌跡。

## 文件角色

- `nine_line_definition_v0.md`：九器官正本。
- `observation_aligned_product_imagination_v0.md`：第一階段成品輪廓。
- `legacy_design_doc_alignment_index_v0.md`：舊文件到九器官的對照來源。
- `clean_rewrite_bootstrap_v1.md`：資料夾地基，不是最終器官定義。

## 第一階段核心循環

```text
硬軟感知模組
→ PerceptionReadableData
→ 學習性泛化應用模組
→ LearningDigest
→ 人類教師審查
→ ReviewedLearningDigest
→ 五重記憶模組
→ MemoryLearningTrace / MemoryApplicationData
→ 思考運算模組
→ ThoughtSignal
→ 擬態具身模組
→ BodyActionSignal
→ 沙盒或環境產生新結果
→ 硬軟感知模組
```

擬態內分泌模組提供狀態調控訊號，穿插影響感知靈敏度、學習消化權重、思考偏向與行動傾向。

## 第一階段目標

第一階段要能看見一筆資料如何從事件變成可讀資料，經過學入、審查、記憶追蹤、讀回，再轉成下一輪身體訊號。

核心不是「立刻會行動」，而是建立可追蹤的成長神經線。
