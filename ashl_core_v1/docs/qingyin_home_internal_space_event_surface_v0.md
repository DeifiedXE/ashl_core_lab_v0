# Qingyin Home Internal Space Event Surface v0

Package 104 defines Qingyin Home as a read-only internal-space event surface.

It can display:

- Host Body identity and ports
- recent fixture-only HostBodyEvent rows
- Runtime EventFrame bridge status
- simple status lights
- teacher-observed summaries
- read-only render snapshots

Qingyin Home is an internal visualization surface, not Qingyin's body, not a Unity runtime connection, not avatar control, and not a desktop assistant UI.

The surface does not start Unity, mutate a scene, control an avatar, connect camera or microphone, create semantic vision or speech recognition, influence action selection, write memory, create teacher approval, create `first_output`, or start a live runtime session.

Safe claim:

ASHL Core v1 can represent Qingyin Home as a read-only internal-space event surface for the Qingyin Host Body, showing host body ports, fixture-only HostBodyEvents, Runtime EventFrame bridge status, simple status lights, teacher-observed summaries, and render snapshots while blocking Unity runtime connection, avatar control, real sensor access, semantic vision, speech recognition, action selection influence, external control, memory-layer writes, teacher approval creation, automatic learning approval, first_output, live runtime sessions, and production behavior.
