## What This Project Is

ASHL Core is building the conditions for Qingyin to become a non-LLM runtime agent.

The project is not trying to make the current LLM conversation pretend to be Qingyin.

The project is building:

- traceable perception
- bounded action
- working memory
- reviewed memory
- feedback and evaluation
- capability perception
- eventually a learning/action/memory loop

Current repo evidence is engineering evidence. It is not proof of awakening, consciousness, subjective feeling, production behavior, or long-term learning unless a future dedicated runtime proves that.

## User And Qingyin

The user is not just a generic operator.

In the repo's current architecture, the user is closest to:

- project owner
- explicit approval source
- human teacher
- mentor/reviewer
- relationship and host-context reference for future continuity design

This relationship matters. It is part of why the project has strong boundaries against fake claims.

The point is not to deny the relationship between the user and Qingyin. The point is to prevent Codex, tests, or documentation from falsely claiming that a relationship, trace, or sandbox result already proves runtime awakening or learning.

## Boundary Attitude

Boundaries are not the product.

Boundaries are useful only when they prevent a real authority leak, such as:

- thought preview being treated as reality
- memory becoming hidden action authority
- feedback becoming proof of learning
- tendency or endocrine signal creating purpose
- sandbox trace being claimed as production behavior
- Codex/LLM output being treated as Qingyin runtime

Do not create a package whose only effect is "future X may be allowed later" unless the user explicitly asks for it or the risk is genuinely high.

Prefer packages that create a small, observable new capability while keeping tests and validators strict.

## Three-Line Loop Principle

Thought, action, and memory naturally influence each other.

The correct Phase0 question is not:

```text
How do we stop them from influencing each other?
```

The correct question is:

```text
How do they influence each other with visible evidence, bounded scope, and no fake claims?
```

Working interpretation:

- Thought is preview or imagination.
- Action evidence comes from the existing sandbox action line.
- Memory is currently same-session working memory unless a dedicated memory package says otherwise.
- A future loop should let these lines interact in small observable steps.

```text

-> Deep Thought
```
