# Memory Influence Candidate Preview Boundary v0

## Purpose

This note defines the preview-only boundary for `memory_influence_candidate` records produced from retained dry-run context.

## Boundary

- Memory influence candidate is preview-only.
- Memory is a warning sign, not a ban command.
- Past failure does not mean the action is forbidden.
- Memory must not override curiosity / exploration.
- Memory must not directly choose final_action.
- Memory must not create direct action commands.
- Memory must not override mentor instruction, safety boundary, or hard runtime gates.

## Not Implemented

- No real memory-influenced behavior.
- No runtime action selection.
- No final_action creation.
- No direct action command.
- No action behavior change.
- No exploration blocking.
- No curiosity override.
- No mentor override blocking.
- No lesson application.
- No memory write or new retention write.
- No predictor mutation.
- No proof-of-learning claim.
