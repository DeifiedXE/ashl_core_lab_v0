# Phase 1-5 Growth Substrate Plan

Status: tentative construction must-read plan.
Runtime impact: none.
Boundary Index impact: none until a package implements a checked record.

This file is a planning guide, not a capability grant. It does not allow production behavior, persistent memory writes, predictor influence, tool access, or consciousness / learning claims by itself.

## Goal

Build ASHL Core from the completed Phase0 thought/action/memory sandbox closure into a broader growth substrate where nine system lines can be observed, checked, and connected.

Plain version:

Qingyin needs a small body of evidence that can remember what happened inside a session, compare expectation with result, use perception and capability maps, admit memory only after review, settle internal state, and keep all authority visible.

## Phase 1: Runtime Session Trace Spine

Purpose:

- Give the Phase0 mini-loop a record-only session spine.
- Add `session_id`, ordered ticks, state snapshots, expected outcome, actual outcome, and evaluator summary.
- Make the loop readable as a small temporal trace instead of isolated records.

Must not:

- Start a live runtime session.
- Create a persistent state store.
- Write long-term memory.
- Create new actions.
- Claim learning or consciousness.

## Phase 2: Perception And Capability Grounding

Purpose:

- Connect vision / eye / focus evidence and Qingyin Bridge capability maps to the session trace.
- Let the system say what was visible, what capability was available, and what was only unknown.

Must not:

- Treat symbolic perception as semantic vision.
- Use capability perception as raw tool authority.
- Execute actions from perception alone.

## Phase 3: Memory Admission And Retention

Purpose:

- Turn selected same-session traces into reviewed memory candidates.
- Separate working memory, reviewed memory, retained memory, and archive intent.
- Add explicit admission checks before any persistent memory path.

Must not:

- Silently persist session traces.
- Treat one sandbox success as habit.
- Let memory bypass purpose, action, or safety gates.

## Phase 4: Layered Thought And State Settling

Purpose:

- Introduce thought layers as checked record types: instinct, specialized thought, coarse thought, and deep thought.
- Connect mimetic endocrine / tendency / settling signals as context, not direct authority.
- Decide when cheap thought is enough and when escalation is needed.

Must not:

- Use an LLM inside Qingyin runtime.
- Let thought preview become observed outcome.
- Let endocrine or tendency create purpose directly.

## Phase 5: Nine-Line Growth Substrate Integration

Purpose:

- Connect all nine system lines into one audited substrate.
- Show how perception, thought, memory, action, state, voice, lesson review, bridge capability, and governance interact without hidden authority.

Nine lines:

1. Action / body-motor line.
2. Thought / purpose formation line.
3. Memory / retention / influence line.
4. Vision / eye / focus line.
5. Qingyin Bridge / capability perception line.
6. Mimetic endocrine / state-settling line.
7. Voice / audio / first-output line.
8. Lesson / review / evidence line.
9. Governance / audit / documentation line.

Must not:

- Collapse all lines into one monolithic thinking module.
- Promote sandbox evidence into production behavior.
- Claim that integration proves consciousness.
