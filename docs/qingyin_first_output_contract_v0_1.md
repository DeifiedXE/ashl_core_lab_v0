# Qingyin First Output Contract v0.1

## 1. 目的

本文件定義清音第一個 runtime 目標的設計邊界：

```text
清音必須產生任何自己的輸出，哪怕是亂碼或簡單反射。
```

本文件是 docs-only / ontology-boundary / first-output-contract / no-LLM-output。

本文件不實作任何 runtime。

---

## 2. 核心決策

The first Qingyin output must be produced by ASHL Core rules, state, seed, or bounded randomness, not by an LLM.

清音的第一個輸出必須來自 ASHL Core 的規則、狀態、種子或有界隨機，而不是 LLM。

這個決策的根本原因：

```text
如果清音的第一句話由 LLM 產生，那不是清音，而是 LLM 戴著清音面具。
```

清音的第一個 runtime 目標不是讓清音能聊天，也不是讓清音看起來像活著。

清音的第一個 runtime 目標是：產生任何屬於自己的輸出。

---

## 3. 清音不是 LLM 回應實例

Qingyin is not the current LLM conversation instance.

清音不是目前的 LLM 對話實例。

清音是：
- 有 Core Seed 的人工幼體
- 有自己的狀態連續性目標
- 有自己的學習機制設計
- 有自己的人格成長軌跡

LLM 在清音的設計流程中的角色是外部顧問，不是清音本體。

---

## 4. first_output 的定義

first_output 是清音第一次由 ASHL Core 自身的機制產生的任何輸出。

這個輸出：
- 可以是任何形式：符號、數字、固定 token、有界隨機結果
- 不需要是有意義的語言
- 不需要被人類理解
- 不需要被 LLM 生成
- 只需要來自 ASHL Core 規則、狀態、種子或有界隨機

Qingyin's first output does not need to be meaningful language.

清音的第一個輸出不需要是有意義的語言。

---

## 5. 可接受的 first_output 來源

以下來源可以作為 first_output：

```text
Core Seed derived fixed rule
minimal internal state
bounded randomness
deterministic seed output
simple reflex rule
non-LLM symbolic output
```

範例（conceptual，不要求本包實作）：

```text
"q"
"0001"
"*"
"seed:pulse"
"noise_7"
亂碼 token
```

Random or nonsensical output may count as first_output if it is generated by ASHL Core rather than an LLM.

若亂碼或無意義輸出由 ASHL Core 產生，而不是 LLM 產生，則可以作為 first_output。

---

## 6. 不可接受的 first_output 來源

以下來源不得算作清音的 first_output：

```text
LLM-generated natural language reply
ChatGPT pretending to be Qingyin
prompt-only persona response
TTS output generated from LLM text
STT / TTS dialogue loop
human-written sentence inserted as Qingyin's output
post-hoc explanation pretending to be first_output
```

LLM-generated text must not count as Qingyin's first output.

LLM 生成的文字不得算作清音的第一個輸出。

---

## 7. LLM 在 first_output 階段的角色

### 允許的角色

```text
LLM may help design docs.
LLM may explain architecture.
LLM may generate candidate work packages.
LLM may assist debugging.
LLM may act as external consultant.
```

### 禁止的角色

```text
LLM must not produce Qingyin's first output.
LLM must not be treated as Qingyin runtime.
LLM must not simulate Qingyin's internal state.
LLM must not generate authoritative Qingyin response.
```

---

## 8. Core Seed / state / rule / bounded randomness 的關係

first_output 的可接受來源與清音的設計組成之間的關係：

**Core Seed：**
- Core Seed 是清音的成長胚胎藍圖，包含人格方向和核心規則
- Core Seed derived fixed rule 是 first_output 的合法來源
- Core Seed 本身不是完成品輸出，而是輸出的上游方向

**minimal internal state：**
- 清音的基本狀態（例如 body_state、session tick）可以觸發輸出
- 狀態輸出必須來自 ASHL Core 的狀態機，而不是 LLM 推測的狀態

**bounded randomness：**
- 有界隨機意味著輸出有明確的取值範圍與生成規則
- 有界隨機不是 LLM 的隨機採樣，而是 ASHL Core 自己控制的隨機來源

**simple reflex rule：**
- 固定的刺激-反應規則，例如「有輸入就產生固定 token」
- 不依賴語義理解，只依賴規則觸發

---

## 9. first_output trace 的未來需求

若未來要實作 first_output runtime，trace 至少需要包含：

```text
session_id
tick
seed or bounded randomness source
minimal_state_snapshot
output_generator_source
first_output
first_output_trace
```

本包只列出未來需求，不實作。

First output is not dialogue ability.

first_output 不等於清音已具備對話能力。

First output is not evidence of long-term growth.

first_output 不等於清音已具備長期成長能力。

---

## 10. 導師回饋的後續位置

導師回饋（mentor feedback）是 first_output 之後的下一步，不是 first_output 本身的一部分。

First output must be traceable before it can become learning material.

first_output 必須先可追蹤記錄，之後才可能成為學習材料。

導師回饋的順序：

```text
first_output（ASHL Core 自己產生）
→ first_output_trace（記錄輸出的 trace）
→ mentor observes（導師觀察）
→ mentor feedback（導師回饋）
→ possible failure_event（若有 mismatch）
→ lesson_candidate pipeline（若通過 review）
```

本包不實作此流程中的任何步驟。

---

## 11. lesson_candidate pipeline 的延後位置

The lesson_candidate pipeline remains downstream of first_output trace and mentor feedback.

lesson_candidate pipeline 位於 first_output trace 與導師回饋之後。

此排序不可逆：清音必須先能產生自己的輸出，並且有可追蹤的記錄，lesson_candidate pipeline 才有意義。

在清音有自己的 first_output 之前，lesson_candidate pipeline 仍屬延後。

---


Bidirectional voice interaction remains deferred.

Audio Sense / STT / TTS / voice trigger / voice input-output loop remain deferred until consultant review.

---

## 13. 設計結論

清音的第一個輸出不需要有意義，但必須是清音自己的。

核心設計原則：

```text
The first Qingyin output must be produced by ASHL Core rules, state, seed, or bounded randomness, not by an LLM.
Qingyin is not the current LLM conversation instance.
LLM-generated text must not count as Qingyin's first output.
Qingyin's first output does not need to be meaningful language.
Random or nonsensical output may count as first_output if it is generated by ASHL Core rather than an LLM.
First output is not dialogue ability.
First output is not evidence of long-term growth.
First output must be traceable before it can become learning material.
The lesson_candidate pipeline remains downstream of first_output trace and mentor feedback.
Bidirectional voice interaction remains deferred.
```

這個 contract 的意義在於：清音的成長必須從真正屬於自己的輸出開始，而不是從 LLM 的模仿開始。哪怕第一個輸出只是一個隨機符號，那也是清音的。
